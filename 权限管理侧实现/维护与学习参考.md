这份文档面向接手维护同学，重点是“先看什么、改哪里、如何验证”。

## 2. 核心知识点（Django/DRF）
1. `permissions`
- Django 权限字典表，每条权限形如 `app_label.codename`。
- 本项目采用白名单权限（`default_permissions=()` + 显式 `Meta.permissions`）。

2. 平台目录与租户运行数据
- 平台目录：`Role / Permission / RolePermissionGrant / QualificationType`
- 租户运行数据：`Tenant / TenantMember / TenantMemberRole / TenantMemberQualification`
- 最终授权链是：`TenantMember -> TenantMemberRole -> RolePermissionGrant -> Permission`

3. `User` 与 `StaffProfile` 的边界
- `User` 只保存账号域信息。
- `StaffProfile` 保存全局人员事实信息。
- `StaffProfile` 不保存业务工号；工号统一放在 `TenantMember.member_no`。
- `superuser` 不允许绑定 `StaffProfile`。
- `platform_admin` 通过 `User.is_platform_admin` 承载。

4. 正式 IAM 运行态
- `unassigned`：已注册但未入租
- `tenant_member`：至少拥有一条成员关系
- `platform_operator`：平台工作态
- `superuser` 不属于正式 IAM 运行态集合

5. Bearer 会话
- 正式 `/api/v1/*` 接口统一使用 Bearer Token。
- 会话模型是 `AuthSession`。
- `session/login`、`session/refresh`、`session/logout` 的实现都在 `apps/access/api_v1/services/auth.py`。

6. 模型级兜底
- 当前大量关键规则已经下沉到模型层的 `clean() + save()->full_clean()`。
- 目的是防止有人绕过 serializer，直接 `model.save()` 写入非法数据。

## 4. 常见改动怎么做
1. 新增业务权限
- 在业务模型 `Meta.permissions` 声明权限码。
- `makemigrations` + `migrate`。
- 在 `seed_role_permissions.py` 里补角色默认授权。

2. 新增平台角色
- 在 `seed_system_roles.py` 里补 `ROLE_DEFINITIONS`。
- 在 `seed_role_permissions.py` 里补该角色的权限矩阵。

3. 调整授权策略
- 优先改 `seed_role_permissions.py` 的基线矩阵。
- 执行 `python manage.py seed_role_permissions --mode replace`。

4. 创建业务账号
- 执行 `python manage.py create_business_admin_account --username <账号> --password <密码>`。
- 该命令只创建账号与 `StaffProfile`，不会直接授予租户角色。
- 如需业务权限，继续创建 `TenantMember` 并分配 `Role`。

5. 调整正式 IAM 接口
- 先改 `apps/access/api_v1/serializers/*` 或 `views/*`
- 再改对应 `services/*`
- 最后更新 `/api/v1/docs/schema/` 对应文档与测试

## 5. 最小验证清单
1. `python manage.py check`
2. `python manage.py test apps.access apps.api_v1`
3. 打开：
- `/docs/`
- `/docs/schema/`
- `/api/v1/docs/`
4. 用业务账号验证：
- `POST /api/v1/iam/session/login`
- `GET /api/v1/iam/me/profile`
- `GET /api/v1/iam/me/tenants`
5. 用租户管理员验证：
- `GET /api/v1/iam/tenant/members`
- `PUT /api/v1/iam/tenant/members/{memberId}/roles`
6. 用平台管理员验证：
- `GET /api/v1/iam/platform/tenants`
- `POST /api/v1/iam/platform/tenants/{tenantId}/initialize-admin`
