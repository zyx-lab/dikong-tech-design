# 业务接口扩展指南（当前版本）

本文说明如何在现有双平面架构下扩展业务接口（`/api/v1/*`），并和权限系统保持一致。

---

## 1. 边界规则

1. IAM 管理能力（用户、角色、scope、审计）只能放在 `/internal/auth/*`。
2. 业务资源能力（无人机、任务、飞行记录等）只能放在 `/api/v1/*`。
3. 业务接口禁止直接操作 `Group/Permission/SystemRole` 元数据表；岗位/资质只能通过 `TenantMemberPosition` / `TenantMemberQualification` 维护。

---

## 2. 扩展步骤

1. 设计业务资源模型。
2. 在模型中声明白名单权限码（`default_permissions = ()`）。
3. 用 DRF ViewSet + `ScopedActionPermission` 接入鉴权。
4. 列表接口用 `ScopedQuerysetMixin` 落地 scope 过滤。
5. 在 `seed_role_permissions` 中配置 `SystemRole -> Group -> Scope` 映射。
6. 补测试与文档。

---

## 3. 权限码设计规范

权限码格式：`<app_label>.<resource>_<action>`

无人机当前示例：
1. `drone.view_drone`
2. `drone.manage_drone`
3. `drone.change_drone_status`
4. `drone.manage_drone_assignment`

模型示例：

```python
class Drone(models.Model):
    class Meta:
        default_permissions = ()
        permissions = [
            ("view_drone", "可查看无人机"),
            ("manage_drone", "可新增与编辑无人机"),
            ("change_drone_status", "可变更无人机状态"),
        ]
```

---

## 4. 接口鉴权接入示例

```python
class DroneViewSet(PermissionMapMixin, ScopedQuerysetMixin, ModelViewSet):
    permission_classes = [ScopedActionPermission]
    permission_map = {
        "list": "drone.view_drone",
        "retrieve": "drone.view_drone",
        "create": "drone.manage_drone",
        "update": "drone.manage_drone",
        "partial_update": "drone.manage_drone",
        "enable": "drone.change_drone_status",
    }

    @staticmethod
    def assigned_scope_filter_builder(staff_id: int) -> dict:
        return {
            "assignments__staff_id": staff_id,
            "assignments__status": "ACTIVE",
        }
```

---

## 5. Scope 设计前提

1. `OWN`：资源中要有创建人字段（例如 `created_by_staff_id`）。
2. `ASSIGNED`：资源中要有指派关系（字段或关联表）。
3. 列表权限必须在 queryset 层过滤，不能只做对象级判断。

无人机当前实现采用关联表 `drone_assignments` 支撑 `ASSIGNED`。

---

## 6. IAM 配置上线流程

1. 在 `seed_role_permissions` 增加新权限码及能力组。
2. 为能力组配置 scope。
3. 为 SystemRole 绑定能力组。
4. 执行：

```bash
python manage.py migrate
python manage.py seed_role_permissions --mode replace
```

如需快速生成业务管理员账号（普通业务账号）：

```bash
python manage.py create_business_admin_account --username biz_root --password 'YourStrongPassword'
```

---

## 7. 测试要求

1. 未登录：拒绝。
2. 无权限：`PERMISSION_DENIED`。
3. 有权限无 scope：`SCOPE_NOT_CONFIGURED`。
4. `OWN/ASSIGNED/ALL` 至少覆盖你实际使用的范围类型。
5. 关键写操作必须断言审计日志。

---

## 8. 常见错误

1. 在业务代码里硬编码 Group 名称做判断。
2. 只配权限不配 scope，导致接口全拒绝。
3. 把 IAM 接口暴露到业务平面。
4. `ASSIGNED` 没有真实关联表支撑，导致过滤逻辑不可维护。
