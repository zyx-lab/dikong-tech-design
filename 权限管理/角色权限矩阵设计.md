# 角色权限矩阵设计（V3 / 双平面）

本矩阵定义的是 **Internal IAM Plane**（`/internal/auth/*`）权限，不是业务资源权限。

统一规则：
- 功能权限来源：`auth_permission`
- 数据范围来源：`auth_group_permission_scopes`
- scope 优先级：`ALL > ASSIGNED > OWN`
- 默认拒绝：有权限但无 scope 配置，拒绝
- 禁用 `user_permissions` 直配
- 禁用用户直绑 Group

## 1. 当前可用能力组与权限

### 1.1 权限策略管理组（`cap_auth_admin`）

| 权限码 | scope | 说明 |
|---|---|---|
| `access.manage_user_accounts` | ALL | 管理账号与人员档案（API） |
| `access.manage_auth_groups` | ALL | 管理 Group 与权限分配 |
| `access.manage_auth_scopes` | ALL | 管理 Group-权限-范围 |
| `access.manage_staff_type_groups` | ALL | 管理 StaffType-Group 映射 |

### 1.2 账号与人员查看组（`cap_user_admin`）

| 权限码 | scope | 说明 |
|---|---|---|
| `access.view_user` | ALL | 查看账号 |
| `access.view_staffprofile` | ALL | 查看人员档案 |

### 1.3 员工自助访问组（`cap_staff_self`）

| 权限码 | scope | 说明 |
|---|---|---|
| `access.view_staffprofile` | OWN | 查看本人档案 |

### 1.4 审计日志只读组（`cap_audit_reader`）

| 权限码 | scope | 说明 |
|---|---|---|
| `access.view_auth_audit_logs` | ALL | 查看审计日志 |

## 2. StaffType -> Group 默认组合

| StaffType | 关联 Group |
|---|---|
| `ops_admin`（运营管理员） | 权限策略管理组, 账号与人员查看组, 审计日志只读组 |
| `route_planner`（航线规划员） | 员工自助访问组 |
| `dispatcher`（任务调度员） | 账号与人员查看组 |
| `pilot_operator`（飞手操作员） | 员工自助访问组 |
| `auditor`（审计员） | 账号与人员查看组, 审计日志只读组 |

## 3. 业务平面扩展提示
业务权限（如 `drone.*`, `mission.*`）不放本矩阵。请在业务接口扩展文档中按资源单独设计。

## 4. 初始化命令
```bash
python manage.py seed_role_permissions --mode replace
```
