# 角色权限矩阵设计（V4 / 当前实现）

本文件描述当前代码中已落地的权限矩阵，覆盖：
1. Internal IAM Plane（`/internal/auth/*`）
2. Business Drone Plane（`/api/v1/drones*` 与 `/api/v1/drone-assignments*`）

统一规则：
- 权限来源：`auth_permission`
- 范围来源：`auth_group_permission_scopes`
- scope 优先级：`ALL > ASSIGNED > OWN`
- 默认拒绝：有权限但无 scope 配置，拒绝
- 禁用 `user_permissions` 直配
- 禁用用户直绑 Group

---

## 1. 能力组与权限

### 1.1 `cap_auth_admin`（权限策略管理组）

| 权限码 | scope | 说明 |
|---|---|---|
| `access.manage_user_accounts` | ALL | 管理账号与人员档案 |
| `access.manage_auth_groups` | ALL | 管理 Group 与权限分配 |
| `access.manage_auth_scopes` | ALL | 管理 Group-权限-范围 |
| `access.manage_staff_type_groups` | ALL | 管理 StaffType-Group 映射 |
| `access.view_registration_application` | ALL | 查看注册申请 |
| `access.manage_registration_application` | ALL | 审核注册申请并开户/驳回 |

### 1.2 `cap_user_admin`（账号与人员查看组）

| 权限码 | scope | 说明 |
|---|---|---|
| `access.view_user` | ALL | 查看账号 |
| `access.view_staffprofile` | ALL | 查看人员档案 |

### 1.3 `cap_staff_self`（员工自助访问组）

| 权限码 | scope | 说明 |
|---|---|---|
| `access.view_staffprofile` | OWN | 查看本人档案 |

| 权限码 | scope | 说明 |
|---|---|---|
| `access.view_auth_audit_logs` | ALL | 查看审计日志 |

### 1.5 `cap_drone_admin`（无人机管理组）

### 1.6 `cap_drone_viewer`（无人机全量查看组）

| 权限码 | scope | 说明 |
|---|---|---|
| `drone.view_drone` | ALL | 全量查看无人机 |

### 1.7 `cap_business_admin`（业务管理员权限组）

| 权限码 | scope | 说明 |

|---|---|---|

## 2. StaffType -> Group 映射

| StaffType | 关联 Group |
|---|---|
| `ops_admin`（Admin管理员） | `cap_auth_admin`, `cap_user_admin`, `cap_audit_reader`, `cap_drone_admin` |
| `business_admin`（业务管理员） | `cap_business_admin` |

## 3. 业务接口动作映射

### 3.0 注册申请

| 接口动作 | 权限码 |
|---|---|
| `POST /api/v1/registration-applications` | `AllowAny`（无需业务角色） |

## 4. 关键行为说明

1. `pilot_operator` 在无人机列表/详情上走 `ASSIGNED` 过滤，只能看到存在 `ACTIVE` 分配关系的无人机。
2. `dispatcher` 可维护分配关系，负责“谁能看到哪架无人机”。
3. `ops_admin` 与 `business_admin` 都拥有无人机业务的全量权限。

## 5. 业务管理员账号创建

可由 superuser 在 IAM 侧执行：

```bash
python manage.py create_business_admin_account --username biz_root --password 'YourStrongPassword'
```

说明：
1. 该命令创建的是普通业务账号（`is_superuser=False`）。
2. 账号会自动绑定 `business_admin` staff_type。
3. 该账号可按矩阵访问全部业务 API。
