PRODUCTION ONBOARDING

接手低空平台，按生产顺序完成部署。

正式环境统一使用 PostgreSQL。先确认域名、端口和持久化目录，再配置密钥，依次启动基础设施与应用，最后完成账号和业务链路验收。

部署前检查

以下条件没有确认前，不要启动应用容器。

运行环境

主机与入口

Docker Compose v2 可用；域名已解析；8000、9000、9001 按网络策略开放，公网入口由 HTTPS 反向代理承接。

持久化

数据与备份

PostgreSQL 和 MinIO 数据卷位于持久磁盘；上线前明确备份、恢复和保留周期。

生产配置

在项目根目录创建仅部署主机可读的 .env。示例值必须全部替换，禁止提交仓库。

01

Django 与 PostgreSQL

数据库容器和应用读取同一组账号配置。

DB_ENGINE=postgres DB_NAME=dikong DB_USER=dikong_app DB_PASSWORD=<strong-database-password> DJANGO_SECRET_KEY=<long-random-secret> DJANGO_DEBUG=false DJANGO_ALLOWED_HOSTS=api.example.com
02

MinIO 与内部回调

对象存储 endpoint 必须是用户浏览器可访问的 HTTPS 地址。

MINIO_ROOT_USER=<storage-access-key> MINIO_ROOT_PASSWORD=<strong-storage-secret> OBJECT_STORAGE_BUCKET_NAME=dikong-route-covers OBJECT_STORAGE_ENDPOINT_URL=https://files.example.com DJI_INTERNAL_API_TOKEN=<shared-callback-token>
03

检查最终配置

确认 Compose 展开结果中没有示例密码、开发密钥或错误域名。

docker compose config

按顺序启动

正式环境六个服务都要部署；先让基础设施健康，再启动应用。

1. db · PostgreSQL 16

业务数据、账号、权限和任务状态的唯一持久化数据库。

等待 healthy

2. redis

Channels、WebSocket 广播和 DJI worker 协作。

等待 healthy

3. minio + minio-init

对象存储常驻；初始化任务创建 bucket 后正常退出。

等待 healthy / completed

4. web + v2-dji-worker

ASGI API 与 DJI MQTT 后台处理必须同时常驻。

保持 Up
01

启动基础设施

docker compose up -d db redis minio minio-init docker compose ps
02

构建并启动应用

web 启动时自动执行迁移、权限目录同步和对象存储迁移。

docker compose up -d --build web v2-dji-worker docker compose ps

上线验收

先验证基础设施与迁移，再创建首个管理员，最后接入 DJI。

01

检查状态与迁移

docker compose ps docker compose exec -T web python manage.py showmigrations --plan docker compose exec -T web python manage.py check --deploy
02

创建首个平台管理员

仅限全新数据库首次部署。命令会重建 v2 初始化数据，已有业务数据时禁止使用 --reset。

read -s ADMIN_PASSWORD docker compose exec web python manage.py bootstrap_v2_system --reset \ --username <platform-admin> --password "$ADMIN_PASSWORD" --noinput unset ADMIN_PASSWORD
03

验证公开入口与后台任务

curl -fsS https://api.example.com/api/v2/docs/schema/ > /dev/null curl -fsS https://files.example.com/minio/health/live > /dev/null docker compose exec -T web python manage.py run_v2_dji_worker --once
